# SKM GAME STUDIOS website

A responsive static portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and current year
- `favicon.svg` — browser tab icon

## Preview locally
1. Extract the ZIP file.
2. Open the `skm_game_studios_website` folder.
3. Double-click `index.html` to open it in your browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `skm-game-studios`.
2. Upload all four website files to the repository root (not the ZIP file).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the deployment and open the URL shown in the Pages settings.

Official guide: https://docs.github.com/en/pages/quickstart
